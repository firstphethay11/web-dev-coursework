# วิธีรันโปรเจค

1. ดับเบิลคลิก `start.cmd` ในโฟลเดอร์นี้
2. เบราว์เซอร์จะเปิด `http://localhost:3001` เมื่อเซิร์ฟเวอร์พร้อม
3. เปิดหน้าต่างคำสั่งค้างไว้ระหว่างใช้งาน กด `Ctrl+C` เพื่อหยุด

ไฟล์นี้รันทั้งหน้าเว็บและ API ให้พร้อมกัน ไม่ต้องเปิด Live Server แยก ต้องติดตั้ง Node.js และเก็บโฟลเดอร์ `louisvuitton-api` ไว้ข้างโฟลเดอร์เว็บตามเดิม หากยังไม่มี dependencies จะติดตั้งผ่าน `npm ci` ให้อัตโนมัติ (ต้องใช้อินเทอร์เน็ต)

ระบบสินค้าและตะกร้าต้องใช้ MySQL ที่มีฐานข้อมูลและตารางเดิม โดยตั้งค่าการเชื่อมต่อใน `../louisvuitton-api/.env` หากขึ้น `Cannot connect to MySQL: ECONNREFUSED` ให้เปิดเซิร์ฟเวอร์ MySQL ที่ใช้งานและตรวจค่าการเชื่อมต่อก่อน ไฟล์รันนี้ไม่ได้ติดตั้งหรือสร้างฐานข้อมูลให้

หากแจ้งว่าพอร์ต 3001 ถูกใช้งานอยู่ ให้ปิดเซิร์ฟเวอร์เดิมก่อนเปิดอีกครั้ง

วิธีรันด้วยคำสั่ง: เข้าโฟลเดอร์ `louisvuitton-api` แล้วรัน `npm start` จากนั้นเปิด `http://localhost:3001` (เมื่อกำหนดพอร์ตเป็น 3001)
